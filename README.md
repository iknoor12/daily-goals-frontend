# Daily Goals Tracker

This repository contains a simple full-stack project: a React frontend and an Express backend.

Folders:
- `frontend` - Vite + React app
- `backend` - Express server

How to run:

1. Backend

```bash
cd backend
npm install
npm start
```

Server will run on http://localhost:4000 by default.

2. Frontend

```bash
cd frontend
npm install
npm run dev
```

Dev server will run on http://localhost:5173 by default.

Notes:
- Currently the frontend uses mock data; it can be later wired to the backend endpoints.
- This project is for learning and demo purposes.
